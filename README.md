## About

I'm a final-year CS student and software/systems engineer, shipping gameplay systems and performance work for multiplayer games on Roblox and Meta Horizon.

I like taking something apart until I understand every layer, then building it back up myself: a renderer, a physics step, an inference pipeline, a machine learning model. What connects it isn't a category, it's my way of working: the discipline and a burning drive to learn and build complex systems, whether that's low-level systems, graphics programming, game design, or an ML pipeline.

## Featured Projects

- **[Tiny Renderer](https://github.com/unyxed/Tiny-Renderer)**: a software 3D renderer in C++17. OBJ loading, 3D rotation, perspective projection, back-face culling, and wireframe rasterization into a CPU framebuffer (SDL2 only displays the result).
- **[RocketBoost](https://github.com/unyxed/RocketBoost)**: a physics-based rocket landing game, with the gameplay written in C++ as a Godot 4 GDExtension.
- **[Tiny Webcrawler](https://github.com/unyxed/tiny-webcrawler)**: an async Python crawler with a concurrency cap, link and content extraction, and JSON reports.
